# Repo-js

* Tienda Urban - Simulador de E-commerce

Proyecto desarrollado en JavaScript para simular el flujo completo de una tienda online.

* Funcionalidades

- Visualización de productos
- Selección de cantidad
- Agregar productos al carrito
- Eliminar productos del carrito
- Cálculo automático del total
- Conservación de datos con localStorage
- Finalización de compra

* Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- DOM
- localStorage

* Flujo de uso

1. El usuario selecciona la cantidad de un producto.
2. Lo agrega al carrito.
3. El carrito muestra los productos seleccionados.
4. Se calcula el total automáticamente.
5. Al finalizar compra se vacía el carrito y se limpia el storage.
